# Pong Game 🎮  
![Python](https://img.shields.io/badge/python-3.x-blue) ![License](https://img.shields.io/badge/license-MIT-green)

A simple Pong game built using Python's `turtle` module. This project uses Object-Oriented Programming (OOP) to organize the game elements.

---

## ✨ Features

- Classic Pong gameplay  
- Two-player control  
- Real-time scoring  
- Game over condition  
- Collision detection  
- Sound effects using `winsound` *(Windows only)*

---

## 🛠 Requirements

- Python 3.x  
- `turtle` module (pre-installed with Python)  
- `winsound` (only for Windows, optional)

---

## 🚀 How to Run

1. Clone the repo:

```bash
git clone https://github.com/Sneha4402/pong-game.git
cd pong-game

2. Run the game:
